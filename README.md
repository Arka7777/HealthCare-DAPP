# 🏥 HealthCare dApp

A decentralized application (dApp) that allows authorized healthcare providers to add and retrieve medical records for patients on the blockchain. Built using **Solidity**, **React**, **Ethers.js v6**, and **Tailwind CSS**.

---

## ✨ Features

- 👨‍⚕️ **Authorize Healthcare Providers** (only by the contract owner)
- 📄 **Add Patient Records** (name, diagnosis, treatment, timestamp)
- 🔍 **Retrieve Patient Records** by patient ID
- 🔐 **Access Control** using modifiers in Solidity
- 💅 Beautiful glassmorphism UI with Tailwind CSS
